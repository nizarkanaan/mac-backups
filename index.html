Mac Backups

Encrypted backups from one Mac to its owner’s Google Drive.

Mac Backups is a personal setup using Backrest, restic, and rclone. When configured and authorized, it reads selected local files, encrypts backup contents and file metadata on the Mac, and uploads the encrypted backup repository to the owner’s Google Drive.

Drive access

The connection requests the drive.file permission. With this rclone configuration, it can manage the Drive files and folders it creates for backups.

Personal use

The setup is operated by its owner for personal backups. This website provides information about the setup; it does not connect visitors to Google Drive or accept files.
